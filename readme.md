# Online Earning Lite

Online Earning Lite is an AI-powered online earning recommendation platform.

## Features

- User Registration & Login
- Razorpay Payment Integration
- AI Suggestion Generator
- Personalized Dashboard
- React Frontend
- Python Backend
- MySQL Database
- Responsive UI

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Python
- Flask / Django

### Database
- MySQL

### Payment Gateway
- Razorpay

### AI Integration
- OpenAI API

---

## Project Flow

1. User Registration
2. Login
3. Payment via Razorpay
4. AI Suggestion Generation
5. Personalized Dashboard
6. Online Earning Recommendations

---

## Installation

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```
